# 红外无人机高空裁剪与数字变焦需求

更新日期：2026-10-08。最新用途是供操作人员观看的红外数字变焦画面，允许使用算力更大的平台和模型，不再以VINS特征跟踪作为下游任务。项目用于定焦红外无人机在更高飞行高度下的裁剪放大与清晰度恢复。现有数据由用户描述为约100米高度拍摄；后续飞行可能达到200米或300米，同一地面目标占用更少像素。目标是放大后真实轮廓更清楚、颗粒更少、目标更容易辨认，连续视频稳定。

此前ORB及VINS前端结果保留为历史资料，跟踪下降不再构成显示候选的淘汰条件。已有实验中的颗粒、重影和结构改变仍属于画质问题。“目前测试模型没有稳定收益”不能推广成所有大模型均无效。新的模型筛选与显示验收见[操作人员观看的优化方案](DISPLAY_ZOOM_PLAN.md)。

操作人员显示的大模型首轮已完成，9组官方权重完成对照；HAT与SwinIR视觉候选完成450帧连续测试，没有新增训练。完整无标注图片、视频及实测边界见[本轮结果](../outputs/操作员显示大模型结果/run_20261008_162935/结果与说明.md)。当前属于PC画质原型，操作人员偏好、实际高空收益和最终平台延迟仍待核实。

## 使用场景与默认输入输出

- 摄像头按用户描述无法光学变焦，现有实拍约在100米高度采集，重点新增200米、300米场景。高度尚未逐帧对照飞行记录。
- 处理链为原始红外帧、选取裁剪区域、上采样或超分恢复、输出放大后的区域图像。
- 优先改善真实轮廓、边缘交汇与操作人员辨识效果；接受有助于观看的适度增强，同时检查过度平滑、光晕及目标形状改变。
- 不再要求用于VINS、ORB或其他机器匹配；特征点数量和保留率不作为模型晋级依据。
- 允许较大算力平台，先在现有PC GPU比较画质并记录显存、速度和延迟。RK3588和轻量部署不再是当前选型约束。
- 暂按现有640×512输入与同尺寸显示输出，覆盖约2倍与3倍；保存网络原生输出，较大显示分辨率作为后续独立对照。实时性预算和最终平台待明确。

## 高度与采样关系

固定镜头、近似俯视、平坦地面和相同姿态条件下，同一目标的线性像素尺寸近似与相机到地面的距离成反比。100米升至200米，同一目标宽度约减半、像素面积约为四分之一；升至300米，宽度约为三分之一、面积约为九分之一。相机整帧仍保持原始分辨率，拍到的地面范围变大。

裁剪保留区域内已有的像素值，本身不会新增模糊；裁剪后放回较大的输出尺寸，低采样、噪声和成像模糊会更明显。超分可以研究边缘与结构恢复，但放大后的像素数量不等于真实有效分辨率，不能保证恢复100米拍摄时的全部信息。

| 示例场景 | 数字变焦倍率 | 640×512帧中裁剪尺寸示例 | 输出暂定 |
|---|---:|---:|---:|
| 200米，希望接近100米的地面观察范围 | 约2倍 | 320×256 | 640×512 |
| 300米，希望接近100米的地面观察范围 | 约3倍 | 约213×171 | 640×512 |

高度与倍率对应依赖相同目标范围和视角。倾斜视角、地形和目标范围会改变关系，倍率不能只由高度自动确定。3倍裁剪涉及像素取整，必须记录实际ROI边界及横纵缩放比例。

## 两类开发测试

**数字变焦实测：** 从现有100米完整图像裁出320×256或约213×171区域，各方法使用相同ROI，恢复为统一输出尺寸。保存裁剪原图、双三次对照和候选完整输出。选建筑交汇、道路、车辆轮廓及低纹理地面等区域，并保留连续帧与时间戳。这回答当前相机图像的裁剪放大效果；区域内原始采样仍来自100米，不等同真实高空成像。

**高度采样损失模拟：** 固定一块地面范围，以100米图像作为相对较清楚的参考，将该范围先按约二分之一或三分之一降低采样分辨率，再恢复。例如100米参考中占640×512的同一地面范围，在200米图中裁出时近似只有320×256，在300米约213×171。先做纯采样退化，再加入温和模糊与噪声，并保存假设。100米图像也是带噪、可能模糊的8位显示灰度，只是相对参考，不是真实HR或温度图。

真实高空还可能受姿态、距离、大气、曝光、振动和增益影响。模拟用于开发初筛，最终需要实际200米、300米场景核实；当前可直接用已有数据开始模拟。

## 评估与实现约束

1. 同一ROI、同一输出尺寸比较真实轮廓、结构定位、光晕、噪声和闪烁。采样模拟增加参考误差，PSNR/SSIM仅作辅助；保持一张输入对应一张完整输出的查看方式。
2. 操作人员评估目标边界、可辨识性、颗粒、自然程度和连续视频闪烁；按片段记录结果，不能只靠PSNR或锐度排名。处理速度、显存和端到端延迟单列，历史VINS分数不进入显示排名。
3. 连续帧先采用固定ROI和倍率。动态ROI另设测试，记录位置、倍率和变换，避免窗口移动本身混入算法收益。
4. 几何结果换回原图或参考坐标，误差阈值按实际缩放比例换算。×2和×3分别验收，已有×2模型仅作为对照；级联×2再缩放须显式标注，不能直接称为原生×3模型。
5. 若训练，以符合本相机、ROI及倍率的采样退化作为输入，参考区域作为目标；按整包或场景划分数据，避免相邻帧泄漏。下载数据作为补充。

## 历史VINS相机模型

以下映射保留用于历史任务与几何溯源，当前操作人员显示用途不要求接入VINS。裁剪与放大后的内参转换中，设ROI左上角为(x0,y0)，实际缩放比例为sx、sy；半像素中心的resize映射下：

```text
fx_new = sx * fx
fy_new = sy * fy
cx_new = sx * (cx - x0 + 0.5) - 0.5
cy_new = sy * (cy - y0 + 0.5) - 0.5
```

其他像素中心映射按实际实现计算，畸变参数的坐标约定保持一致。动态ROI或倍率需要每帧支持对应相机模型，不能继续使用固定旧内参。初期先做固定ROI，沿用采集时间戳，独立测量处理延迟。

## 实施顺序

1. 冻结约2倍、3倍和默认640×512输出，保存实际ROI边界与取整规则。
2. 用本地连续帧建立裁剪实测与采样损失模拟两套数据，保存参考、倍率、时间戳及退化假设。
3. 输出双三次、V13等插值和已有超分的统一尺寸对照，分别评估×2、×3。
4. 比较较大模型的结构保真版本与视觉增强版本，先验证预训练迁移效果，再决定红外数据适配训练。
5. 对候选进行同尺寸整图和连续视频人工复核，结合实际平台与延迟预算选择运行模式；后续核实真实高空效果。
